摘要

主流序列转导模型通常建立在复杂的循环神经网络或卷积神经网络之上，并采用编码器-解码器结构。性能最好的模型还会通过注意力机制连接编码器与解码器。本文提出一种新的、结构更简单的网络架构：Transformer。它完全基于注意力机制，彻底舍弃循环结构和卷积结构。

在两项机器翻译任务上的实验表明，Transformer 在质量上优于既有模型，同时具有更强的并行化能力，训练所需时间显著减少。在 WMT 2014 英译德任务上，模型达到 28.4 BLEU，比包括集成模型在内的既有最佳结果高出 2 个 BLEU 以上。在 WMT 2014 英译法任务上，单模型在 8 块 GPU 上训练 3.5 天后达到 41.8 BLEU，训练成本仅为文献中最佳模型的一小部分。论文还通过英语成分句法分析任务说明，Transformer 能够很好地泛化到翻译之外的任务。

1 引言

循环神经网络，尤其是长短期记忆网络和门控循环网络，长期是语言建模、机器翻译等序列建模与序列转导问题中的主流方法。许多研究持续推进循环语言模型和编码器-解码器架构的边界。

循环模型通常沿输入和输出序列的符号位置分解计算。若将序列位置与计算时间步对齐，模型会根据前一隐藏状态和当前位置输入生成隐藏状态序列。这种内在的顺序性使训练样本内部难以并行化。当序列较长时，内存限制又会限制跨样本批处理规模，因此顺序计算成为效率瓶颈。尽管分解技巧和条件计算能改善效率，顺序计算这一根本约束仍然存在。

注意力机制已经成为序列建模和转导模型的重要组成部分。它允许模型不受输入或输出序列距离的限制来建模依赖关系。然而在多数情形中，注意力仍然与循环网络结合使用。

本文提出的 Transformer 抛弃循环结构，完全依靠注意力机制在输入与输出之间建立全局依赖。由于这种架构允许显著更高程度的并行化，它可以在 8 块 P100 GPU 上仅训练约 12 小时后，在翻译质量上达到新的最佳水平。

2 背景

减少顺序计算同样是 Extended Neural GPU、ByteNet 和 ConvS2S 等模型的核心动机。这些模型以卷积神经网络为基础，对所有输入和输出位置并行计算隐藏表示。它们的问题在于：两个任意位置之间建立联系所需的操作数会随位置距离增长。ConvS2S 中这种增长是线性的，ByteNet 中则是对数级的。这会使模型更难学习远距离依赖。

Transformer 将任意两个位置之间的依赖路径缩短为常数数量的操作。代价是注意力加权平均可能降低有效分辨率，论文通过多头注意力机制来抵消这一影响。

自注意力又称内部注意力，是一种在单个序列的不同位置之间建立关系、进而计算序列表示的注意力机制。它已经成功用于阅读理解、抽象式摘要、文本蕴涵以及任务无关句子表示学习等任务。

据论文作者所知，Transformer 是第一个完全依赖自注意力来计算输入和输出表示的转导模型，它不使用按序列位置对齐的 RNN，也不使用卷积。后续章节将说明 Transformer 的结构，解释采用自注意力的动机，并比较它相对于循环和卷积模型的优势。

3 模型架构

大多数竞争力强的神经序列转导模型采用编码器-解码器结构。编码器把输入符号表示序列映射为连续表示序列；解码器再基于这些表示逐个生成输出符号。每一步生成都具有自回归性质，即生成下一个符号时会使用此前已经生成的符号作为额外输入。

Transformer 沿用这一整体框架，但在编码器和解码器中都采用堆叠的自注意力层与逐位置全连接层。原论文图 1 展示了编码器与解码器的左右两部分结构。

3.1 编码器与解码器栈

编码器。编码器由 N = 6 个相同层堆叠而成。每层包含两个子层：多头自注意力机制，以及逐位置全连接前馈网络。每个子层外部使用残差连接，随后进行层归一化。形式上，子层输出为 LayerNorm(x + Sublayer(x))。为了支持这些残差连接，模型中的所有子层以及嵌入层都输出 d_model = 512 维表示。

解码器。解码器同样由 N = 6 个相同层堆叠而成。除了编码器层中的两个子层外，解码器还插入第三个子层，对编码器栈的输出执行多头注意力。解码器中的自注意力子层经过掩码处理，禁止当前位置关注后续位置。该掩码与右移的输出嵌入共同保证位置 i 的预测只能依赖小于 i 的已知输出。

3.2 注意力

注意力函数可以描述为：将一个查询和一组键-值对映射为输出。查询、键、值和输出都是向量。输出是值向量的加权和，每个值的权重由查询与相应键之间的兼容性函数计算得到。

论文采用的是缩放点积注意力。输入包含维度为 d_k 的查询和键，以及维度为 d_v 的值。模型计算查询与所有键的点积，将每个点积除以 sqrt(d_k)，再用 softmax 得到值向量上的权重。

Attention(Q, K, V) = softmax(QKT / sqrt(dk))V

点积注意力和加性注意力在理论复杂度上相近，但点积注意力能用高度优化的矩阵乘法实现，因此在实践中更快、更节省空间。当 d_k 较大时，未缩放的点积可能幅度过大，使 softmax 落入梯度极小的区域。缩放因子 1 / sqrt(d_k) 正是为了抵消这一问题。

3.2.2 多头注意力

相比只执行一次 d_model 维的注意力，论文发现将查询、键和值分别线性投影 h 次更有效。每次投影后并行执行注意力函数，得到多个低维输出；这些输出拼接后再次线性投影，形成最终结果。

MultiHead(Q, K, V) = Concat(head1, ..., headh)WO
headi = Attention(QWiQ, KWiK, VWiV)

多头注意力让模型能够在不同位置同时关注来自不同表示子空间的信息。单个注意力头往往会因平均化而削弱这种表达能力。论文使用 h = 8 个并行注意力头，每个头取 d_k = d_v = d_model / h = 64，因此总计算成本与单头全维注意力大体相当。

3.2.3 注意力在模型中的三种用法

第一，在编码器-解码器注意力层中，查询来自上一层解码器，键和值来自编码器输出。这使解码器每个位置都能关注输入序列的所有位置。第二，编码器包含自注意力层，键、值和查询都来自编码器上一层输出，编码器中每个位置都可关注上一层所有位置。第三，解码器自注意力层允许每个位置关注当前位置及其之前的位置，但通过掩码阻止未来信息流入，以保持自回归性质。

3.3 逐位置前馈网络

除注意力子层外，编码器和解码器的每层还包含一个全连接前馈网络。它对每个位置分别且相同地应用，由两个线性变换和中间的 ReLU 激活组成。

FFN(x) = max(0, xW1 + b1)W2 + b2

这些线性变换在不同位置共享，但不同层之间使用不同参数。也可以把它理解为两个卷积核大小为 1 的卷积。输入和输出维度为 d_model = 512，中间层维度为 d_ff = 2048。

3.4 嵌入与 Softmax

模型使用学习得到的嵌入将输入与输出 token 转换为 d_model 维向量，并使用线性变换和 softmax 将解码器输出转换为下一个 token 的概率分布。论文在两个嵌入层与 softmax 前线性变换之间共享同一个权重矩阵，并在嵌入层中将权重乘以 sqrt(d_model)。

3.5 位置编码

由于模型不含循环和卷积，必须向输入中注入关于 token 相对或绝对位置的信息。论文在编码器和解码器底部的输入嵌入中加入位置编码。位置编码与嵌入具有相同维度，因此二者可以直接相加。

PE(pos, 2i) = sin(pos / 100002i / d_model)
PE(pos, 2i + 1) = cos(pos / 100002i / d_model)

其中 pos 是位置，i 是维度。每个位置编码维度对应一个正弦曲线，波长按几何级数变化。作者选择这种函数，是因为它可能使模型更容易学习相对位置关系：对于任意固定偏移 k，PE(pos + k) 可表示为 PE(pos) 的线性函数。论文也测试了学习式位置嵌入，结果与正弦位置编码几乎相同，但正弦版本更可能外推到训练时未见过的更长序列。

4 为什么是自注意力

论文从三个标准比较自注意力层、循环层和卷积层。第一，每层总计算复杂度。第二，可并行计算的程度，具体用所需最少顺序操作数衡量。第三，网络中远距离依赖之间的路径长度。学习远距离依赖是许多序列转导任务的关键挑战；前向和反向信号在网络中需要经过的路径越短，学习这种依赖就越容易。

层类型 每层复杂度 顺序操作数 最大路径长度
自注意力 O(n² d) O(1) O(1)
循环层 O(n d²) O(n) O(n)
卷积层 O(k n d²) O(1) O(logk n)
受限自注意力 O(r n d) O(1) O(n / r)

自注意力层以常数数量的顺序操作连接所有位置，而循环层需要 O(n) 个顺序操作。当序列长度 n 小于表示维度 d 时，自注意力在计算复杂度上也比循环层更快。现代机器翻译系统常用的 word-piece 和 byte-pair 表示中，这种条件通常成立。

对于很长的序列，可以将自注意力限制在局部邻域内，以改善计算性能，但最大路径长度会增加到 O(n / r)。卷积层若要连接任意一对位置，往往需要堆叠多层卷积；即使使用可分离卷积，其复杂度也与自注意力加逐位置前馈层的组合相当。

论文还指出，自注意力有潜在的可解释性优势。作者观察注意力分布后发现，单个注意力头会学习到不同功能，许多头表现出与句法和语义结构相关的行为。

5 训练

5.1 训练数据与批处理

英德任务使用标准 WMT 2014 English-German 数据集，约 450 万个句对。句子通过 byte-pair encoding 编码，源语言和目标语言共享约 37000 个 token 的词表。英法任务使用更大的 WMT 2014 English-French 数据集，约 3600 万个句子，并使用 32000 个 word-piece 的词表。句对按近似序列长度组成批次，每个训练批次约包含 25000 个源 token 和 25000 个目标 token。

5.2 硬件与训练计划

模型在一台配备 8 块 NVIDIA P100 GPU 的机器上训练。基础模型每步约 0.4 秒，共训练 100000 步，约 12 小时。大模型每步约 1.0 秒，共训练 300000 步，约 3.5 天。

5.3 优化器

论文使用 Adam 优化器，β1 = 0.9，β2 = 0.98，ε = 10^-9。学习率在训练过程中按如下公式变化：

lrate = d_model-0.5 · min(step_num-0.5, step_num · warmup_steps-1.5)

这意味着学习率在最初 warmup_steps 个训练步内线性上升，之后按步数的平方根倒数下降。论文取 warmup_steps = 4000。

5.4 正则化

论文使用残差 dropout 和标签平滑。残差 dropout 应用于每个子层输出，在其与子层输入相加并归一化之前执行；嵌入与位置编码相加后的结果也使用 dropout。基础模型的 dropout 率为 0.1。标签平滑取 ε_ls = 0.1，它会使困惑度变差，因为模型学习得更不确定，但可以提升准确率和 BLEU 分数。

6 结果

6.1 机器翻译

在 WMT 2014 英译德任务上，Transformer big 模型达到 28.4 BLEU，超过此前包括集成模型在内的最佳结果 2.0 BLEU 以上，建立了新的最佳水平。即使是基础模型，也以远低于竞争模型的训练成本超过了此前已发表的模型和集成模型。

在 WMT 2014 英译法任务上，大模型取得 41.8 BLEU 的单模型成绩，训练成本低于此前最佳模型的四分之一。论文还使用 checkpoint 平均、beam search、长度惩罚等推理设置，以获得稳定结果。

模型 英译德 BLEU 英译法 BLEU 要点
Transformer base 27.3 38.1 训练成本低，已超过此前多个公开模型。
Transformer big 28.4 41.8 在论文报告的主要翻译任务上达到当时最佳或单模型最佳水平。

6.2 模型变体

论文通过改变注意力头数、键和值的维度、模型深度、前馈层维度、dropout 和位置编码方式来评估 Transformer 各组件的重要性。结果显示：单头注意力比最佳设置低 0.9 BLEU，注意力头过多也会降低质量；减小键维度会损害模型质量，说明兼容性判断并不容易；更大的模型通常表现更好；dropout 对防止过拟合很有帮助；用学习式位置嵌入替换正弦位置编码，结果几乎相同。

6.3 英语成分句法分析

为了验证 Transformer 是否能泛化到其他任务，论文在英语成分句法分析上进行了实验。该任务输出具有强结构约束，且输出长度通常明显长于输入。作者在 Penn Treebank 的 WSJ 数据上训练 4 层 Transformer，并在半监督设置中使用更大的高置信语料。尽管没有针对任务做大量调参，模型仍获得了很强结果，在仅使用 4 万句 WSJ 训练数据时也超过 BerkeleyParser。

7 结论

论文提出了 Transformer，这是第一个完全基于注意力的序列转导模型。它用多头自注意力替代了编码器-解码器架构中常见的循环层。

在翻译任务中，Transformer 的训练速度显著快于基于循环或卷积层的架构，并在 WMT 2014 英德和英法任务上达到新的最佳水平。作者认为注意力模型具有广阔前景，计划将 Transformer 扩展到文本之外的输入和输出模态，并研究局部、受限注意力机制，以高效处理图像、音频和视频等大规模输入输出。同时，减少生成过程的顺序性也是后续研究目标之一。

译读要点：Transformer 的革命性不只是“用了注意力”，而是把注意力从辅助机制提升为序列转导架构的主体机制。它同时解决了远距离依赖路径、训练并行化和模型表达子空间分工三个问题。

核心术语表

sequence transduction
序列转导，指将一个序列映射为另一个序列的任务，如机器翻译。
self-attention
自注意力，同一序列内部不同位置之间相互计算注意力。
encoder-decoder attention
编码器-解码器注意力，解码器查询编码器输出，以对输入序列整体进行条件化。
scaled dot-product attention
缩放点积注意力，通过除以 sqrt(d_k) 稳定 softmax 梯度。
multi-head attention
多头注意力，并行地在不同表示子空间中执行注意力，再拼接投影。
position-wise feed-forward network
逐位置前馈网络，对每个位置独立应用同一个两层前馈变换。
positional encoding
位置编码，为无循环、无卷积的模型提供序列位置信息。
label smoothing
标签平滑，降低模型对硬标签的过度自信，常能提升泛化和 BLEU。
