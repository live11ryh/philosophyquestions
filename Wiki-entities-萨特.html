让-保罗·萨特 (Jean-Paul Sartre)

"L'existence précède l'essence."
"存在先于本质。"
—— 《存在主义是一种人道主义》

生平简介

让-保罗·萨特（1905-1980），法国哲学家、作家、剧作家，20世纪最有影响力的存在主义思想家之一。

主要轨迹

  • 早年：出生于巴黎，母亲早逝，在外祖父家长大
  • 巴黎高师：结识波伏瓦，开启终身伴侣关系
  • 战俘营经历：二战期间被俘，在战俘营接触海德格尔
  • 《存在与虚无》 (1943)：存在主义的奠基之作
  • 拒绝诺贝尔奖 (1964)：拒绝接受任何官方荣誉
  • 1968年："三M事件"（Mao, May, Marx）中的激进立场

主要著作

《存在与虚无》(L'Être et le Néant, 1943)

萨特最系统的哲学著作，论证自由的绝对性和他人的困境。

《存在主义是一种人道主义》(L'existentialisme est un humanisme, 1946)

面向公众的演讲，简化了《存在与虚无》的核心论点。

其他重要著作

  • 《想象》(1936)
  • 《恶心》(1938) - 小说
  • 《墙》(1939) - 短篇小说集
  • 《辩证理性批判》(1960)

核心思想

1. 存在先于本质 (Existence precedes Essence)

萨特最著名的命题。

| 传统观点 | 萨特 |
|----------|------|
| 本质先于存在（上帝造人） | 存在先于本质 |
| 物有固定本质 | 人没有固定本质 |
| 人在被创造前就被定义了 | 人首先存在，然后定义自己 |
"人首先存在，然后定义自己。"

2. 虚无化 (Néantisation)

萨特对胡塞尔意向性的激进化：

  • 意识不是物：它没有内在内容，不是一个"东西"
  • 意识是虚无：正因为不是物，所以能否定、超越、创造
  • 虚无化：意识通过"不是"某物而存在
| 胡塞尔 | 萨特 |
|--------|------|
| 意识构成对象 | 意识是虚无 |
| 先验自我 | 无自我 |
| 意向性 = 指向对象 | 意向性 = 虚无化活动 |

3. 自在与为自 (En-soi & Pour-soi)

萨特的存在二元论：

| 自在 (En-soi) | 为自 (Pour-soi) |
|----------------|------------------|
| 存在自身 | 意识存在 |
| 是其所是 | 是其所不是 |
| 充盈、完整 | 欠缺、开放 |
| 无意识 | 有意识 |
| 无自由 | 绝对自由 |

4. 绝对自由

萨特的自由是"无处可逃"的：

  • 自由不是选择：自由是存在本身
  • 被判定为自由：无论你是否选择，你都被判定为自由的
  • 责任：自由的代价是绝对的责任
"人被判定为自由。"

5. 他人的凝视 (Le Regard d'Autrui)

  • 他人的目光：他人看我时，把我变成一个"对象"
  • 羞耻与自我意识：通过他人的凝视，我意识到自己的"身体"
  • 主奴关系的逆转：我试图通过凝视他人来夺回主体性

与胡塞尔的对比

| 胡塞尔 | 萨特 |
|--------|------|
| 意识是意向性 | 意识是虚无化 |
| 自我是构成中心 | 意识无内在实体 |
| 先验还原 | 无还原的必要 |
| 重点是意义构成 | 重点是自由 |
| 意向性指向对象 | 意识逃离自身 |

与海德格尔的关系

萨特受海德格尔深刻影响，但也有重要区别：

| 海德格尔 | 萨特 |
|----------|------|
| 此在的生存结构 | 意识的虚无化 |
| 向死存在 | 绝对自由 |
| 本真性 | 真诚 (Authenticity) |
| 遗忘存在 | 执着于"自我" |

关键引语

"存在先于本质。"
"他人即是地狱。"
"人是无用的激情。"
"意识是虚无——正因为它不是物，它才能是自由的。"

影响与争议

哲学影响

  • 存在主义的普及化
  • 马克思主义的存在主义化
  • 后结构主义的批判对象

争议

  • 与共产党关系的摇摆
  • 对阿尔及利亚战争的态度
  • 晚年对苏联的维护
