萨特《存在与虚无》(L'Être et le Néant)

基本信息

  • 作者：让-保罗·萨特 (Jean-Paul Sartre)
  • 出版：1943年
  • 副标题：《存在与虚无：论现象学本体论》
  • 意义：存在主义的奠基之作，系统论证自由的绝对性

核心问题

萨特在《存在与虚无》中追问：

"是否存在一种理解人的方式，既不把人还原为物，也不把人还原为意识？"

他的回答是：通过区分"自在存在"与"为自存在"。

核心结构：存在的两种样态

1. 自在存在 (L'Être-en-soi)

| 特征 | 描述 |
|------|------|
| 定义 | 存在自身，是其所是 |
| 性质 | 充盈、完整、封闭 |
| 特点 | 无裂缝、无欠缺、无可能性 |
| 类比 | 像石头一样"是"自己 |
自在存在没有意识，不选择，不筹划，只是"是"。

2. 为自存在 (L'Être-pour-soi)

| 特征 | 描述 |
|------|------|
| 定义 | 意识存在，是其所不是 |
| 性质 | 欠缺、开放、逃离 |
| 特点 | 永远"不是"自己的在场 |
| 核心 | 虚无化 |
为自存在（意识）通过"不是"某物而存在。

核心概念

虚无化 (Néantisation)

萨特的核心发现：意识的存在方式是否定。

基本结构：

意识 = 对某物的意识
     = "不是"该物
     = 在自身中包含"虚无"

例证：

  • 我去咖啡馆找皮埃尔，但皮埃尔不在
  • 这个"不在"不是咖啡馆的属性，而是我意识中的"虚无"
  • 正是这个虚无使得寻找成为可能

意向性 (Intentionnalité)

萨特继承并激进化了胡塞尔的意向性：

"一切意识都是关于某物的意识。"

但萨特强调：

  • 意识没有内在内容
  • 桌子不在意识"里面"，而是在空间中
  • 意识是纯粹的外指

反思前的我思 (Le Cogito Préréfléchi)

萨特的起点是笛卡尔的我思，但加上了重要修正：

| 笛卡尔 | 萨特 |
|--------|------|
| 我思故我在 | 我思（怀疑/感知） |
| 思考的"我" | 没有内在的"我" |
| 实体二元论 | 存在论二元论 |
"意识没有'自我'。意识是对某物的意识。"

自由的本体论论证

萨特论证自由不是人的一个属性，而是人存在的结构本身。

论证结构

  1. 虚无化：意识永远"不是"自己的在场
  2. 可能性：意识的存在包含可能性
  3. 选择：意识总是面对"可能性"
  4. 自由：无法逃脱的选择

自由的特征

| 特征 | 描述 |
|------|------|
| 无处可逃 | 自由不是选择的结果，而是存在的前提 |
| 被判定为自由 | 人无法选择是否自由 |
| 绝对责任 | 自由意味着绝对的责任 |
| 焦虑 (Angst) | 面对自由的眩晕 |
"人被判定为自由。"

他者问题

萨特认为他者问题是存在论的核心问题。

基本结构

  1. 我的意识：对某物的意识，无内在自我
  2. 他者的目光：他者看我，把我变成对象
  3. 羞耻：我意识到自己是"对象"
  4. 冲突：我试图通过看他者来夺回主体性

关键段落

"他人即是地狱。"

这不是说他人总是有害，而是说：

  • 当我被他者对象化时，我失去了主体性
  • 我无法完全控制他者如何看我
  • 主体间的承认永远是不对称的

恶的问题

萨特用虚无化来解释"恶"的本体论根源。

恶不是存在

  • 自在存在无所谓善恶
  • 恶来自为自存在的虚无化结构
  • 恶是我"选择"不选择（bad faith）

自欺 (Mauvaise Foi)

自欺是萨特对"自我欺骗"的本体论分析：

| 真诚 | 自欺 |
|------|------|
| 意识到自己的自由 | 逃避自由 |
| 承担存在 | 把自己当作物 |
| 本真性 | 沉沦 |

例证：

  • 咖啡馆服务员：过度扮演角色，把自己当作物
  • 爱情的占有者：试图把他者变成"自在"

与胡塞尔的对话

萨特承认受胡塞尔影响，但提出重要修正：

| 胡塞尔 | 萨特 |
|--------|------|
| 先验自我 | 无内在自我 |
| 意向性 = 指向 | 意向性 = 虚无化 |
| 现象 = 被给予 | 现象 = 被超越 |
| 还原 → 先验域 | 无需还原 |

关键引语

"存在先于本质。"
"自在存在是其所是。为自存在是其所不是。"
"意识是虚无——正因为它不是物，它才能是自由的。"
"人被判定为自由。"
"他人即是地狱。"
"人是无用的激情。"

全书结构

| 部分 | 内容 |
|------|------|
| 第一部分：否定的起源 | 虚无化，虚无如何在世界中出现 |
| 第二部分：自为的存在 | 为自存在的详细分析 |
| 第三部分：为他存在 | 他者问题，我与他人的关系 |
| 第四部分：拥有、作为、存在 | 实践存在论 |
